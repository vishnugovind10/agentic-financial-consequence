# Design lineage

This repository is a small independently written composition layer. It reuses public concepts and interfaces, not source code or private checkout contents.

```text
agent-trust-probe → authorized intent → consequence binding
institutional-settlement-state-machine → lifecycle and observed financial state
control-probe → deterministic scenario and stress fixtures
liquid-witness / liquid-proofpack → independent evidence boundary
institutional-digital-asset-assurance → evidence-aware final decision
```

Related public projects: [agent-trust-probe](https://github.com/vishnugovind10/agent-trust-probe) informs authority and exposure inputs; [institutional-settlement-state-machine](https://github.com/vishnugovind10/institutional-settlement-state-machine) informs settlement, finality and reconciliation states; [institutional-digital-collateral-stack](https://github.com/vishnugovind10/institutional-digital-collateral-stack) informs liquidity and collateral consequences; [control-probe](https://github.com/vishnugovind10/control-probe) informs executable deterministic scenarios; [liquid-witness](https://github.com/vishnugovind10/liquid-witness) and [liquid-proofpack](https://github.com/vishnugovind10/liquid-proofpack) inform independent observability and evidence boundaries; [institutional-digital-asset-assurance](https://github.com/vishnugovind10/institutional-digital-asset-assurance) informs explicit `PASS`/`FAIL`/`ABSTAIN` semantics. `temporal-liquidity-risk`, `tokenize-stack`, `agentic-economy-observatory`, and `coordination-fabric` provide adjacent public context.

The new contribution is the binding between granted authority and observed economic consequence, plus lifecycle conformance across state, settlement, liquidity, reconciliation and evidence. It does not recreate agent identity, runtime governance, wallet policy or settlement processing.
